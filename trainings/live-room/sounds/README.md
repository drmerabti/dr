# أصوات غرفة التدريب المباشر

ضع هنا أي ملف من الملفات التالية بنفس الاسم (mp3). الكود يبحث عن كل ملف:
إن وُجد يشغّله، وإن لم يوجد يستعمل البديل المولّد بـ Web Audio أو الصمت.
(بدون أي موسيقى.)

| الملف | الاستعمال | البديل إن لم يوجد |
|---|---|---|
| ambience.mp3 | همهمة القاعة في الانتظار (حلقة، صوت منخفض) | صمت |
| bell.mp3 | ظهور السؤال | جرس مولّد يتلاشى |
| tick.mp3 | تكّة العدّاد كل ثانية | نقرة مولّدة |
| heartbeat.mp3 | آخر 5 ثوانٍ (والتكّات تتسارع) | دقتان منخفضتان مولّدتان |
| correct.mp3 | إجابة صحيحة | نغمة قصيرة صاعدة |
| wrong.mp3 | إجابة خاطئة | صوت منخفض قصير |
| applause.mp3 | ظهور الترتيب | صمت |
| cheer.mp3 | صاحب التاج / الفائز العام | صمت |
